# Стоматологический магазин

Демонстрационная витрина стоматологических товаров для клиник и домашнего ухода. Каталог открывается сразу при переходе на сайт.

- Фильтры по категориям помогают быстро найти нужные материалы, инструменты или средства ухода.
- В карточке товара видны цена и характеристики. В корзине можно изменить количество и увидеть общую стоимость.
- При оформлении можно выбрать регион и посмотреть примерную стоимость и срок доставки.
- Интерфейс открывается на русском. Кнопка в шапке позволяет переключить магазин на английский, сохранив выбранные товары в корзине.

Демонстрационные заказы оформляются без списания денег и отправки посылок.
